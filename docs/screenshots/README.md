# Portfolio screenshots

These images use synthetic local demo data. Regenerate them after starting the local
stack and Vite:

```powershell
npm.cmd --prefix frontend run capture:screenshots
```

Set `E2E_BASE_URL`, `E2E_API_URL`, `E2E_DEMO_PASSWORD`, or `PLAYWRIGHT_CHANNEL` when
the defaults do not match the target environment. Review every image before publishing.
The script captures no passwords, tokens, environment settings, or browser storage.
